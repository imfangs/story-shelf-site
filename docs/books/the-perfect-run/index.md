# The Perfect Run

<p class="book-author">完美通关 · Maxime J. Durand</p>

<ReadingTools id="the-perfect-run" />

一位能设置时间存档的冒险者来到新罗马城。在英雄、罪犯与企业势力之间，他反复尝试不同路线，寻找自己的完美结局。

## 为什么可能喜欢

时间循环、游戏多周目与黑色幽默。

<p class="book-facts">长篇小说 · 奇幻与科幻<br>有血腥暴力、粗口及成人话题；面向成年读者筛选。</p>
